# notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

## 本目录特有约束

- **第 3 行必须是状态行**：`状态：生效 / 被取代 / 已否决 / 已归档`，四值之一，不允许自造。
- **决策类必须写替代方案**：没写「试过什么、为什么不行」的决策不算记录，下次必被重诉。
- **依据类不强制替代方案**：依据本身只是输入，没有选项；有对照分析时才写。
- **归档就地标记**：改第 3 行为 `状态：已归档` + 一句话理由，不移动文件、不建子目录。
- **已实施的事实用现在时**：写「脚本使用 PowerShell」，不写「我们决定改用 PowerShell」。
- **决策反转才写新记录**：事实性变化（路径、默认值）就地更新原记录，不新增文件。

## 命名

- 决策：`YYYY-MM-DD-<主题>`
- 依据：可省日期，用 `<主题>` 即可

## 不写什么

- 迁移计划、验收清单 → `docs/PLAN.md`
- 事故复盘 → `docs/postmortem/`
- spec 式「应该怎样」 → 归 `docs/ARCHITECTURE.md`

记录怎么组织、去哪查见 [README.md](README.md)。
