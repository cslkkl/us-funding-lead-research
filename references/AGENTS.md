# references/ — 规则层

继承根规则，见 [../AGENTS.md](../AGENTS.md)。

## 本目录特有约束

- **事实必须可回溯**：每条数据要能指回原始来源（SEC 申报、官网页面、新闻稿）。写「某公司融资 X」，必须说清 X 来自 Form D 的哪一列。
- **不写未验证的推断**：不确定就写「未找到」，不写「可能是」。
- **数字与 `data/` 同步**：改 `field-notes.md` 的统计值时，必须同时确认 `data/final_leads.csv` 的实际行数对得上。
- **案例要带代价**：写坑的时候写清「花了多少时间 / 错了多少条」，不写「要注意 X」。
- **不复制 SKILL.md 的流程**：流程只有 [SKILL.md](../SKILL.md) 一个 home，这里只放流程失效的具体案例。

## my-answer.md 的特殊约束

它是一份完整答案，**不是活文档**：记录的是某一次作业的事实，不随后续代码演进追改。

后续若流程变化，新写一份记录，不改这份。

文件职责与阅读顺序见 [README.md](README.md)。
