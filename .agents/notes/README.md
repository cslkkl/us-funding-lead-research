# .agents/notes/ — 决策与依据记录

记录「为什么这么定」，不随后续演进追改。规则层约束见 [AGENTS.md](AGENTS.md)。

## 两类记录

| 类型 | 触发源 | 装什么 | 命名 |
|---|---|---|---|
| 决策 | 面对岔路口，选了 A 不选 B | 问题、决策、替代方案、影响 | `YYYY-MM-DD-<主题>` |
| 依据 | 做调查，看事实得结论 | 背景、结论、（可选）支撑的决策、影响 | 可省日期 |

## 状态行规则

每篇第 3 行必须是状态行，四值之一：

- `状态：生效` —— 仍在指导当前工作
- `状态：被取代` —— 必须跟指针行，指向新记录
- `状态：已否决` —— 必须跟一句话理由
- `状态：已归档` —— 就地标记，不建 `archived/` 子目录

## 什么时候要写

- 在两个以上方案之间做了选择 → 决策
- 做了一次勘察 / 评估 / 对照，结论会影响后续 → 依据
- 同一件事事后可能被重新提出 → 必须写，否则下次重诉

## 什么时候不用写

- 只有一个显然选项 → 不构成决策
- 事故触发的复盘 → 去 `docs/postmortem/`，不来这里
- 一次性尝试且已验证失败、不影响后续 → 记进根 `AGENTS.md` 活跃坑即可
