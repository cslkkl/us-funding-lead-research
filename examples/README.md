# examples/ — 样例输出

一次完整运行的结果，用来对照格式，不是工具的一部分。

## 2026Q3-demo/

2026 年第三季度跑出来的真实结果，160 家美国科技公司。

| 文件 | 行数 | 说明 |
|---|---|---|
| [final_leads.csv](2026Q3-demo/final_leads.csv) | 160 | 完整线索清单 |
| [scored.csv](2026Q3-demo/scored.csv) | 160 | 加上五维打分 |
| [top20.csv](2026Q3-demo/top20.csv) | 20 | 人工排除后按分数排序 |

## 这份数据能用来做什么

- **对照输出格式**：自己跑完脚本后，看列名和取值对不对
- **验证流程是否正常**：如果你跑出来的 `verified` 占比远低于 60%，说明探测环节可能有问题

## 不能用来做什么

- **直接当客户名单用**：这是 2026 Q3 的快照，融资状态、公司业务、负责人可能已经变化
- **当作你所在市场的答案**：不同业务方向的 ICP 不同，筛选阈值要重定

## 字段说明

| 列 | 说明 |
|---|---|
| `Company` | 品牌名（非 Form D 法定名） |
| `AmountM` | 实际融资额（百万美元），取自 `TOTALAMOUNTSOLD` |
| `Domain` | 官网，未确认时为空 |
| `Business` | 一句话中文业务描述，来自官网实访 |
| `Contact` / `Title` | 负责人与职务 |
| `Email` | 页面公开邮箱 |
| `Status` | `verified` / `partial` / `not_found` |
| `Score` / `Excluded` | 仅 scored / top20 有 |

## 实测命中率（可作基准）

| 指标 | 结果 |
|---|---|
| 有官网 | 148 / 160（92.5%） |
| 有实名负责人 | 110 / 160（68.8%） |
| 有公开邮箱 | 90 / 160（56.3%） |
| 其中个人邮箱 | 18 个 |

若你的结果显著低于这个基准，先查域名探测是否被停放页干扰。
